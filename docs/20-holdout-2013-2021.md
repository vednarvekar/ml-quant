# 20 - Holdout test on 2013-2021 (frozen candidates)

Why: paper trading needs months of new data. A faster check: run the exact same frozen
strategies on years we never used to choose any setting. All choices (model v3, 5-day label,
k, rebalance every 5 days, account sizes) were made on 2022-2026. The 2013-2021 predictions
are walk-forward (each day scored by a model trained only on earlier days). Nothing re-fitted.

`uv run python -m mlq.holdout` -> `data/clean/holdout_results.csv`, `holdout_yearly.csv`

## What this means

- The market-neutral idea holds up on 9 unseen years about as well as on 2022-2026 (0.76 vs 0.70)
  and its alpha t-stat (2.67) is the first one above 2. That is real evidence, not proof.
- Long-only still does not clearly beat the index on a risk basis (alpha t 1.5).

## Caveats (why it is not proof)

1. **Missing stocks.** We have prices for only 58-75% of the F&O stocks of each year
   (our 255-symbol list was picked from today's large stocks). Missing names are partly
   delisted/shrunk companies. This flatters long-only much more than L/S, but L/S is not immune.
2. **Open fills only.** No 5-minute data before 2022, so the realistic-fill haircut can't be
   checked here. On 2022-2026 it cut L/S Sharpe from 0.70 to ~0.45; expect similar.
3. Lot sizes are inferred from open interest; margins are a flat 20%.

## Round 2: missing stocks filled in (survivorship fix)

`uv run python -m mlq.backfill` builds daily prices for 583 stocks we had no Upstox data for
(delisted, merged, shrunk, or simply not downloaded) from the NSE cash bhavcopy. Splits/bonuses are
detected from the overnight gap and confirmed by futures open interest jumping by the same ratio
(379 adjustments; e.g. Colgate and Mindtree 1:1 bonuses). Old symbols are mapped to the latest
name (CADILAHC -> ZYDUSLIFE etc.) for prices, F&O membership and delivery %.
F&O coverage 2013-2021 is now **100%** (was 58-75%). Research only: switched on with
`MLQ_BACKFILL=1`; the paper trader is unchanged. Model v3 retrained walk-forward on the wider set
(`ml_v3_bf_pred_raw.npy`, same settings).

| Test | ML L/S k=10 Sharpe | alpha t | random L/S | ML long-only | random long-only |
|---|---|---|---|---|---|
| 2013-2021, old data (58-75% coverage) | 0.76 | 2.67 | -0.91 | 0.98 | 0.51 |
| 2013-2021, full coverage | **1.22** (1.17-1.26) | **4.38** | -1.06 | 1.09 (t 2.04) | 0.08 |
| 2013-2021, full, big jumps (>35%, demergers) zeroed | 1.31 | 4.66 | -1.01 | 1.12 | 0.08 |
| **2022-2026, full coverage (same model)** | **0.42** (0.25-0.70) | 1.29 | -1.52 | | |

L/S by year (full coverage): 2013 +23%, 2014 +29%, 2015 +19%, 2016 +15%, 2017 -5%,
2018 +33%, 2019 +39%, 2020 +15%, 2021 -5%.

### Reading it honestly
- Filling the missing stocks made the old-years result **stronger**, not weaker, and it is not
  driven by crashes or demergers (zeroing them changes little). Random picks still lose.
  So survivorship was not what made the strategy look good.
- But the same model is **much weaker since 2022** (Sharpe 0.42, alpha t 1.3; and realistic
  fills cut 2022+ results by about a third, so ~0.3). Last 3 of 4 calendar years 2021-2026 are weak.
  Most likely explanation: the short-term pattern it exploits has been **fading** as Indian
  markets got more crowded with algos. That is the key risk.
- Verdict: real historical edge, uncertain present edge. Not ready for real money.
